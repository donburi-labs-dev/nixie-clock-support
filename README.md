# Nixie Clock - Support

Support page for the Nixie Clock widget for CORSAIR XENEON EDGE (iCUE).

## Reporting a problem
Please open an Issue and include:
- Nixie Clock version (shown on the Marketplace page)
- iCUE version
- Widget slot size (S / M / L / XL)
- A screenshot if possible

For purchase or refund questions, please contact Elgato Marketplace support.
